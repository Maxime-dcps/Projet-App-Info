RetroSwap is a web application built with **ASP.NET Core MVC** that functions as a peer-to-peer (P2P) marketplace for buying and selling retro video games, consoles, and accessories.

## Key features

- **User Accounts:** Secure user registration and login.
- **Listings Management (CRUD):** Authenticated users can create, read, update, and delete their own listings.
- **Multi-Image Upload:** Users can upload multiple images for each listing.
- **Tagging System:** Listings can be categorized with tags for better organization.
- **Search & Filter:** Users can search for listings by keywords, filter by tags, and sort results by date, price, or popularity.
- **Favorites System:** Users can add listings to a personal favorites list.
- **Admin Capabilities:** Basic moderation features for managing tags and listings.

## Technologies

- **C#** & **ASP.NET Core**
- **Dapper** (for data access)
- **PostgreSQL** 
- **Razor Pages**
- **Bootstrap 5**
